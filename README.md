# Description

This repository houses the artifact for Master's Thesis at the Vrije
Universiteit Amsterdam.

`scripts/` houses the scripts that help re-run some of the steps presented in
the evaluation. Some steps are manual, thus results are provided in their raw
form, such as LLM logs and manually compiled results in the form of markdown
files.

`img/` contains all the figures used in the paper.

`prompts/` houses all the system prompts discussed in the paper.
`system.fullex-alt` is used in *fuzzing a real project*. This prompt makes some
optimization that allows better consistent patch geneartion by limiting LLM
code generation only for the specified target function.

`patches/` has diff files with modificaitons to the sub-modules used in this
project. OSS-fuzz, for example, does not work properly without some
modifications to the Docker infrastructure.

`experiments/` holds the three folders that contain the static, historic, and
fuzzing tests which were then used to produce the graphs presented in the
paper.

# Setup

To install the requirements use the `setup.sh` scripts in the root directory.

All the dependenccies used in the project are as follow:
- clang 20.1.8-1
- llvm 20.1.8-1
- llvm-libs 20.1.8-1
- Python 3.13.5

Python uses a virtual environement auto-generated by the `setup.sh` script.

Use `source bootstrap.sh` to set-up the path and python environemnt.
